🚀 ¿Cómo desplegar en GitHub Pages?

Esta carpeta ya está 100% preparada con index.html y el archivo .nojekyll para que cualquier persona en el mundo pueda jugar desde su navegador o tablet.

1

Sube tu repositorio a GitHub

Crea un nuevo repositorio en GitHub (público) y sube todos los archivos de esta carpeta (usando GitHub Desktop, VS Code o la consola):

git init
git add .
git commit -m "Publicar juegos matemáticos"
git branch -M main
git remote add origin https://github.com/TU-USUARIO/TU-REPOSITORIO.git
git push -u origin main
2

Activa GitHub Pages en la Configuración

En la página de tu repositorio en GitHub:

  1. Haz clic en la pestaña Settings (Configuración).
  2. En el menú lateral izquierdo, haz clic en Pages.
  3. Bajo Build and deployment, en Source deja Deploy from a branch.
  4. En Branch selecciona main y carpeta / (root).
  5. Haz clic en el botón Save.
3

¡Listo! Comparte el enlace

En 1 o 2 minutos, GitHub generará tu sitio web público gratuito en la dirección:

https://TU-USUARIO.github.io/TU-REPOSITORIO/
💡
Compatibilidad total: Todos los juegos usan código HTML/CSS/JS nativo sin dependencias de servidor. Funcionan en computadoras, Chromebooks, iPads y celulares.
